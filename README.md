# 🧁 Bakerz Bite

> Freshly baked happiness in every bite.

Bakerz Bite is a responsive bakery website for a Karachi-based bakery. Visitors can browse cakes, pastries, cookies and pies, add items to a cart, claim special offers, shop branded merch, and get in touch with the bakery.

🔗 **Live demo:** [hasan6969macho-bit.github.io/Bakerz-Bite](https://hasan6969macho-bit.github.io/Bakerz-Bite/)

---

## ✨ Features

- **Interactive menu**: filter by category (All, Cakes, Pastries, Cookies, Pies) with a "no products found" state for empty searches
- **Shopping cart**: add items, review your order, and see a running total in PKR
- **Product details**: view the description and ingredients of each item
- **Special offers**: seasonal deals on birthday cakes, cookie boxes and coffee & cake combos
- **Branded merch**: mugs, bags, glasses and serving trays
- **Photo gallery**: a showcase of fresh bakes
- **FAQ**: answers on same-day delivery, custom cakes and how to order
- **Feedback**: a 5-star rating section
- **Contact form** with an embedded Google Map
- **Visitor counter** and a hero video banner
- **Fully responsive** layout for desktop and mobile

## 🚀 Getting Started

No build tools or dependencies are needed.

1. **Clone the repository**
   ```bash
   git clone https://github.com/hasan6969macho-bit/Bakerz-Bite.git
   ```
2. **Open the project folder**
   ```bash
   cd Bakerz-Bite
   ```
3. **Run it**: open `index.html` in your browser, or use a local server such as the VS Code *Live Server* extension.

## 🌐 Deployment

The site is deployed with GitHub Pages:

1. Go to **Settings → Pages** in your repository
2. Under **Source**, choose the `main` branch and the `/ (root)` folder
3. Save, and your site will be live within a minute or two
